## 🚀 快速开始

```bash
# 安装依赖（Node >= 18）
npm install

# 本地开发
npm run dev

# 生产构建
npm run build        # 产物输出到 dist/，可直接部署任意静态服务器

# 本地预览构建
npm run preview
```

## 📦 部署

`dist/` 为纯静态产物，直接上传 Nginx / Vercel / Netlify / OSS / COS / GitHub Pages 等任意静态托管即可，无需任何后端配套。

详细部署步骤、广告接入方法、SEO 与后续扩展说明，请阅读 [DEPLOY.md](./DEPLOY.md)。

## 📁 项目架构

```
src/
├─ config/tools.ts       全站工具统一配置（路由/SEO/功能边界/处理器映射）
├─ core/                 纯前端处理引擎
│  ├─ processors.ts      全部 13 个工具处理器
│  ├─ pdfjs.ts           pdfjs-dist worker 初始化
│  ├─ utils.ts           文件/下载/缩略图等通用工具
│  └─ types.ts           ProcessFn 类型定义
├─ components/           Header / Footer / 安全横幅 / 广告位
├─ layouts/MainLayout.ts 全局布局
└─ pages/                首页 / 工具落地页模板 / 免责 / 隐私 / 404
```

新增任何前端工具，只需在 `config/tools.ts` + `core/processors.ts` 各加一条，即可在首页与路由中自动出现。
